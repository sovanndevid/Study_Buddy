# Sprint 3 - Childcare Card Template

## 📌 Project Brief

For Sprint 3, I designed a colourful and engaging card for a childcare-themed website. The goal is to create a fun, welcoming experience for young children and their parents. The card features a cheerful tiger image and a simple “Say Hi!” interaction to help make the site feel friendly and approachable. This template sets the tone and style for the rest of the site, using soft colours, large fonts, and playful visuals suitable for a childcare audience.

## 💡 Design Hypothesis

I believe that using friendly characters, soft colours, and minimal content will make the interface more inviting for young users and parents. The tiger card is designed to capture attention, create a sense of joy, and encourage interaction, helping build trust and engagement from the first impression.
